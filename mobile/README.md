# PlatIO Mobile

Aplicación móvil oficial de PlatIO.

## Objetivo

Configurar la central y las macetas sin paneles técnicos y recibir notificaciones push nativas.

## Tecnología decidida

- React Native
- Expo SDK 57 (estable)
- TypeScript
- Expo Notifications
- Supabase
- Provisioning BLE seguro del ESP32

SDK 58 está actualmente en beta; el MVP queda fijado en SDK 57 estable.

## Pantallas MVP

1. Bienvenida
2. Escanear QR de central
3. Conectar central al Wi‑Fi
4. Mis macetas
5. Elegir planta
6. Estado de maceta
7. Historial
8. Ajustes / diagnóstico

Ver `../docs/APP_ARCHITECTURE.md` y `../docs/UX_ZERO_FRICTION.md`.
